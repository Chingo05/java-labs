Циклы while и do-while: аналогия «Качаем пресс до усталости» while және do-while циклдері: «Шаршағанша пресс жасау» аналогиясы

Цикл while (с предусловием) сначала проверяет условие, и только если оно истинно (true), выполняет тело цикла. Представьте тренировку: пока остались силы (energy > 0), вы делаете повтор и тратите 1 единицу энергии (energy--). Если сил изначально 0 — вы не сделаете ни одного повтора.

while циклі (алғышартты) алдымен шартты тексереді, тек ол ақиқат (true) болса ғана орындалады. Жаттығуды елестетіңіз: күш бар кезде (energy > 0) қайталау жасап, 1 бірлік энергия азайтасыз (energy--). Егер күш басынан 0 болса — цикл бір рет те орындалмайды.

Цикл do-while (с постусловием) сначала выполняет действие, а проверяет условие в самом конце. Поэтому он гарантированно сработает хотя бы 1 раз (удобно для меню или запроса ввода).

do-while циклі (соңғы шартты) алдымен әрекетті орындап, шартты ең соңында тексереді. Сондықтан ол кем дегенде 1 рет міндетті түрде орындалады.

⚠️ Ловушка бесконечного цикла (Infinite Loop)Шексіз цикл тұзағы (Infinite Loop) Если внутри while (energy > 0) забыть написать energy--, условие никогда не станет false — программа зависнет навсегда! Для управления циклом также используют break (мгновенный выход из цикла) и continue (пропуск текущей итерации и переход к следующей). Егер while (energy > 0) ішінде energy-- жазуды ұмытсаңыз, шарт ешқашан false болмайды — бағдарлама мәңгілікке қатып қалады! Циклді басқару үшін break (циклден бірден шығу) және continue (ағымдағы қадамды өткізіп жіберу) қолданылады.
WhileDemo.java 
int energy = 3;

// Цикл while (предусловие)
while (energy > 0) {
    System.out.println("Делаем повтор! Сил: " + energy);
    energy--; // Важно! Без этого будет бесконечный цикл
}
System.out.println("Тренировка окончена!");

// Цикл do-while (выполнится минимум 1 раз)
int x = 0;
do {
    System.out.println("Сработал хотя бы раз! x = " + x);
} while (x > 0);

Цикл for («Школьный стадион») и генератор Random for циклі («Мектеп стадионы») және Random генераторы

Когда заранее известно точное число повторений, используют for (int i = 1; i <= 5; i++). Аналогия «Школьный стадион»: физрук четко сказал пробежать ровно 5 кругов — вы начинаете с 1-го (int i = 1), бежите пока i <= 5, и после каждого круга счетчик сам растет на единицу (i++).

Қайталау саны алдын ала нақты белгілі болса, for (int i = 1; i <= 5; i++) қолданылады. «Мектеп стадионы» аналогиясы: дене шынықтыру мұғалімі дәл 5 айналым жүгіруді тапсырды — 1-ден бастайсыз (int i = 1), i <= 5 болғанша жүгіресіз, әр айналымда есептегіш өседі (i++).

🎲 Как работает java.util.Random?java.util.Random қалай жұмыс істейді? Метод rand.nextInt(N) всегда выдает целое число от 0 до N - 1 (включая 0, но НЕ включая N). Поэтому rand.nextInt(6) даст 0, 1, 2, 3, 4, 5. Чтобы получить грани кубика от 1 до 6, нужно просто прибавить 1: int dice = rand.nextInt(6) + 1;. rand.nextInt(N) әдісі әрқашан 0-ден N - 1-ге дейін бүтін сан береді (N саны кірмейді). Сондықтан rand.nextInt(6) нәтижесі 0..5 болады. Сүйектің 1-ден 6-ға дейінгі мәнін алу үшін 1 қосамыз: int dice = rand.nextInt(6) + 1;.
ForAndRandom.java 
import java.util.Random;

public class Main {
    public static void main(String[] args) {
        Random rand = new Random();

        for (int i = 1; i <= 5; i++) {
            int dice = rand.nextInt(6) + 1; // от 1 до 6
            System.out.println("Круг #" + i + " | Выпало: " + dice);
        }
    }
}

Задача 6.16.1-есеп

🔐 «Тренажер пин-кода с 3 попытками и Копилка (10 000 тг)» «3 әрекетті ПИН-код тренажері және Жинақ сандығы (10 000 тг)»

  1. Создайте класс PinAndPiggyBank. Задайте верный ПИН int correctPin = 7777; и счетчик попыток int attempts = 0;.PinAndPiggyBank класын құрыңыз. Дұрыс ПИН int correctPin = 7777; және әрекет санағышын int attempts = 0; беріңіз.
  2. В цикле while (attempts < 3) запрашивайте ПИН через Scanner. Если ПИН верный — выходите через break. Если 3 раза неверно — выведите «Карта заблокирована!» и завершите программу.while (attempts < 3) циклінде Scanner арқылы ПИН сұраңыз. Дұрыс болса break арқылы шығыңыз. 3 рет қате болса «Карта бұғатталды!» деп аяқтаңыз.
  3. После успешного входа запустите Копилку: в цикле while (saved < 10000) пользователь вводит взносы в тенге, пока сумма не достигнет или не превысит 10 000 тг. В конце выведите итоговую накопленную сумму.Сәтті кіргеннен кейін Жинақ сандығын іске қосыңыз: while (saved < 10000) циклінде сома 10 000 тг-ге жеткенше жарна енгізіп отырыңыз.
PinAndPiggyBank.java (Каркас) 
import java.util.Scanner;

public class PinAndPiggyBank {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int correctPin = 7777, attempts = 0;
        boolean access = false;

        while (attempts < 3) {
            System.out.print("Введите ПИН-код: ");
            int pin = sc.nextInt();
            attempts++;
            if (pin == correctPin) {
                access = true;
                break;
            }
            System.out.println("Неверно! Осталось попыток: " + (3 - attempts));
        }

        if (!access) {
            System.out.println("Карта заблокирована!");
            return;
        }

        int saved = 0;
        while (saved < 10000) {
            System.out.print("Внесите сумму (тг): ");
            saved += sc.nextInt();
            System.out.println("Накоплено: " + saved + " / 10000 тг");
        }
        System.out.println("Цель достигнута! Итого: " + saved + " тг");
    }
}

🚀 «Таймер обратного отсчета ракеты» «Зымыранның кері санақ таймері»

Напишите программу RocketTimer, которая с помощью цикла while выводит обратный отсчет от 10 до 1, уменьшая счетчик на 1 на каждом шаге (count--), а сразу после выхода из цикла печатает «Поехали!».

while циклін пайдаланып 10-нан 1-ге дейін кері санақ шығаратын (count--), ал цикл аяқталған соң «Кеттік!» деп жазатын RocketTimer бағдарламасын жазыңыз.

RocketTimer.java 
public class RocketTimer {
    public static void main(String[] args) {
        int count = 10;
        while (count >= 1) {
            System.out.println("До старта: " + count);
            count--;
        }
        System.out.println("Поехали! 🚀");
    }
}

Задача 7.17.1-есеп

🔑 «Генератор надежных паролей и таблица умножения» «Сенімді құпия сөз генераторы және көбейту кестесі»

  • Часть 1 (Пароль): Запросите длину пароля int len. Создайте строку доступных символов String chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789!@#$%";. В цикле for (int i = 0; i < len; i++) берите случайный индекс rand.nextInt(chars.length()) и добавляйте символ chars.charAt(index) к паролю.1-бөлім (Құпия сөз): Ұзындығын int len сұраңыз. for циклінде Random арқылы кездейсоқ таңбаларды таңдап, құпия сөз құрастырыңыз.
  • Часть 2 (Таблица): Запросите число int n и в цикле for (int i = 1; i <= 10; i++) выведите таблицу умножения: n + " x " + i + " = " + (n * i).2-бөлім (Кесте): int n санын сұрап, for (int i = 1; i <= 10; i++) циклінде көбейту кестесін шығарыңыз.
PasswordAndTable.java 
import java.util.Random;
import java.util.Scanner;

public class PasswordAndTable {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        Random rand = new Random();
        String chars = "ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnpqrstuvwxyz23456789!@#$%";

        System.out.print("Длина пароля: ");
        int len = sc.nextInt();
        String password = "";
        for (int i = 0; i < len; i++) {
            int idx = rand.nextInt(chars.length());
            password += chars.charAt(idx);
        }
        System.out.println("Ваш пароль: " + password);

        System.out.print("Число для таблицы умножения: ");
        int n = sc.nextInt();
        for (int i = 1; i <= 10; i++) {
            System.out.println(n + " x " + i + " = " + (n * i));
        }
    }
}

Задача 7.27.2-есеп

🎲 «Симулятор броска двух игральных кубиков (10 раз подряд)» «Екі ойын сүйегін лақтыру симуляторы (қатарынан 10 рет)»

Напишите программу DiceSimulator. Цикл for (int i = 1; i <= 10; i++) делает ровно 10 бросков двух кубиков: int d1 = rand.nextInt(6) + 1; и int d2 = rand.nextInt(6) + 1;. Выведите оба числа, их сумму, а если d1 == d2 — увеличьте счетчик дублей doublesCount++. В конце выведите общее число дублей.

DiceSimulator бағдарламасын жазыңыз. for циклі 10 рет екі сүйекті лақтырады (rand.nextInt(6) + 1), екі санды және олардың қосындысын шығарады. Егер d1 == d2 болса, дубль санағышын арттырып, соңында жалпы дубль санын көрсетіңіз.

DiceSimulator.java 
import java.util.Random;

public class DiceSimulator {
    public static void main(String[] args) {
        Random rand = new Random();
        int doubles = 0;

        for (int i = 1; i <= 10; i++) {
            int d1 = rand.nextInt(6) + 1;
            int d2 = rand.nextInt(6) + 1;
            System.out.println("Бросок " + i + ": [" + d1 + "] и [" + d2 + "] | Сумма: " + (d1 + d2));
            if (d1 == d2) {
                doubles++;
            }
        }
        System.out.println("Всего выпало дублей: " + doubles);
    }
}
