2 главные ошибки новичков в Java: Java-дағы 2 басты қате:

1. Путаница = и ==: Одинарное = — это присваивание (положить в коробку: pin = 7777). Двойное == — это вопрос-сравнение (if (pin == 7777)).
2. Сравнение строк (String): Текст в Java нельзя сравнивать через == (оно сравнивает ссылки в памяти). Для строк всегда используйте метод .equals(): if (pass.equals("admin")).

1. = мен == шатастыру: Жалғыз = — бұл меншіктеу (pin = 7777). Қос == — салыстыру сұрағы (if (pin == 7777)).
2. Жолдарды (String) салыстыру: Java-да мәтінді == арқылы салыстыруға болмайды. Жолдар үшін әрқашан .equals() әдісін қолданыңыз: if (pass.equals("admin")).

🎬 Задача «Касса кинотеатра со скидками» 🎬 «Жеңілдігі бар кинотеатр кассасы» есебі

Напишите класс CinemaCashier. Программа через Scanner запрашивает возраст зрителя (int age) и сумму заказа в буфете (double sum).

CinemaCashier класын жазыңыз. Бағдарлама Scanner арқылы көрерменнің жасын (int age) және буфеттегі тапсырыс сомасын (double sum) сұрайды.

  • Если возраст до 12 лет (age < 12) — скидка 50%.Егер жасы 12-ге дейін (age < 12) — жеңілдік 50%.
  • Если студент — до 22 лет включительно (age <= 22) — скидка 30%.Егер студент — 22 жасқа дейін қоса алғанда (age <= 22) — жеңілдік 30%.
  • Иначе (else) — полная цена (0%).Әйтпесе (else) — толық баға (0%).
  • Обязательно проверьте пограничные числа: 11, ровно 12, ровно 22 и 23 года!Шекаралық сандарды міндетті түрде тексеріңіз: 11, дәл 12, дәл 22 және 23 жас!
CinemaCashier.java (Каркас) 
import java.util.Scanner;

public class CinemaCashier {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Введите возраст зрителя: ");
        int age = sc.nextInt();
        System.out.print("Сумма заказа в буфете (тг): ");
        double sum = sc.nextDouble();

        double discount = 0;
        if (age < 12) {
            discount = 0.50;
        } else if (age <= 22) {
            discount = 0.30;
        } else {
            discount = 0.0;
        }

        double finalPrice = sum * (1 - discount);
        System.out.println("Скидка: " + (int)(discount * 100) + "%");
        System.out.println("К оплате: " + finalPrice + " тг");
    }
}
